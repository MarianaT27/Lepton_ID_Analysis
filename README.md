# Lepton_ID_Analysis

Analysis code, plots, and benchmarking scripts for the CLAS12 lepton PID BDT/MLP classifier
(companion to the [Lepton_AI_PID](https://github.com/MarianaT27/Lepton_AI_PID) repo, from which
`plot.C` and `ratios.C` are pulled).

## Contents

- **`plot.C`**, **`ratios.C`** — the two analysis macros actively used to produce this repo's
  plots (selected because both have a 2026 modification date, unlike `plot_tagged.C` and
  `Efficiency.C`, which are older). They read TMVA-scored ROOT trees and produce the PDFs in
  `Plots/`.
- **`Plots/`** — every PDF plot generated by `plot.C`/`ratios.C`, mirroring the original
  `Results/` subfolder structure (including `Results/Article/Figure_5`, `Figure_8`, `Figure_9`,
  `Figure_10`) to keep same-named plots from different figures distinct.
- **`Files/`** *(not tracked in git — see below)* — the ROOT input files `plot.C`/`ratios.C`
  need to run, copied locally so the code runs with relative `Files/...` paths instead of the
  original hardcoded absolute paths. Reproduce locally with:
  ```
  Files/9-BDT/{F18in,F18out}_{positives,negatives}_Final.root
  Files/6-BDT/{F18in,F18out}_{positives,negatives}_Final.root
  Files/Result_v2/pos_F18in_BDT_modFC.root
  ```
  (Originals live under `/Users/mariana/Documents/LeptonID/rootValidation/` — see git history
  of this README or ask if you need the exact source paths again.)
- **`Timing_Benchmark/`** — reproducible training/inference timing benchmark for the paper
  review (see `Timing_Results.md` for the numbers already measured). `run_benchmark.sh` +
  `templates/*.C` regenerate and rerun everything on any machine with the same data layout;
  `README_ifarm.md` has JLab ifarm-specific setup (module/conda ROOT, SLURM submission).
- **`Timing_Results.md`** — training and inference timing for the BDT and MLP models, at both
  6-variable and 9-variable feature sets, measured on both MC and real Data.

## What's intentionally not in this repo

Large ROOT data files are kept out of git (see `.gitignore`) since they're regenerable and would
bloat the repo permanently:
- `Files/` (~215 MB) — copies of validation ROOT files also available at their original path.
- Training samples and TMVA weight files used by the timing benchmark — not stored here at all;
  `Timing_Benchmark/README_ifarm.md` documents where they need to point via environment
  variables (`ROOTTRAINING_DIR`, `WEIGHTS6_DIR`, `WEIGHTS9_DIR`).
