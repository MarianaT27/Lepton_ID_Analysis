# Lepton_ID_Analysis

Analysis code, plots, and benchmarking scripts for the CLAS12 lepton PID BDT/MLP classifier
(companion to the [Lepton_AI_PID](https://github.com/MarianaT27/Lepton_AI_PID) repo, from which
`plot.C` and `ratios.C` are pulled).

## Contents

- **`plot.C`**, **`ratios.C`** — the two analysis macros actively used to produce this repo's
  plots (selected because both have a 2026 modification date, unlike `plot_tagged.C` and
  `Efficiency.C`, which are older). They read TMVA-scored ROOT trees and produce the PDFs in
  `Plots/`.
- **`Plots/`** — every PDF plot generated by `plot.C`/`ratios.C`, mirroring the original
  `Results/` subfolder structure (including `Results/Article/Figure_5`, `Figure_8`, `Figure_9`,
  `Figure_10`) to keep same-named plots from different figures distinct.
- **`Files/`** — the ROOT input files `plot.C`/`ratios.C` need to run (~215 MB, largest file 28
  MB, well under GitHub's 100 MB limit), so the repo is self-contained and the code runs as-is
  with its relative `Files/...` paths. Originals live under
  `/Users/mariana/Documents/LeptonID/rootValidation/` on the analysis machine.
- **`Weights/ML_weights_pass2/`** — trained BDT and MLP weight files (6-var and 9-var) for all 6
  datasets (F18in/F18out/S19 × pos/neg). These are the actual trained models used throughout this
  repo's inference timing numbers — small enough (~20 MB) to track directly in git, unlike the
  training data (see below).
- **`Timing_Benchmark/`** — reproducible inference timing benchmark for the paper review (see
  `Timing_Results.md` for the numbers already measured). `run_benchmark.sh` +
  `templates/*.C` regenerate and rerun everything on any machine — `WEIGHTS_DIR` defaults to
  `Weights/ML_weights_pass2/` above automatically, so cloning this repo is enough to run inference
  timing with zero configuration. `README_ifarm.md` has JLab ifarm-specific setup (module/conda
  ROOT, SLURM submission) for getting a comparison inference-timing number there.
- **`Timing_Results.md`** — training and inference timing for the BDT and MLP models, at both
  6-variable and 9-variable feature sets, measured on both MC and real Data. Training was done on
  local compute (never on ifarm), so training-time numbers are Mac-only.

## What's intentionally not in this repo

- MC training samples (`rootTraining/`, ~438 MB) — needed only for the training leg of
  `Timing_Benchmark/run_benchmark.sh` (`ROOTTRAINING_DIR`). These are much larger, not needed to
  run `plot.C`/`ratios.C` or the inference benchmark, and training was done on local compute and
  never existed on ifarm anyway — see `Timing_Benchmark/README_ifarm.md`.
